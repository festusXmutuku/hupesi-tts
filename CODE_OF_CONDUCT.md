# Code of Conduct

This project follows the [Contributor Covenant version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Summary:
- Treat everyone with respect, regardless of experience, gender, age, location, or viewpoint.
- Critique ideas, not people.
- Do not harass, insult, or share other people's private information.

Violations may result in comment removal, issue locks, or a ban from the project. To report a violation, contact the project owner privately via GitHub.
